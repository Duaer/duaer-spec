          Duaer-spec FDE · model
          
          
          配置模型
          
        
          
        
      
          
      
          
        
          先接好 Duaer 台面模型，再在台面说需求。写入 ~/.duaer/live/config.json
          

        
          
          台面模型
          
          
            
          
              服务商
              
          
            
          
            
            
            
            
            
          
            
          
              怎么填？
              
            
                
          1. 选 DeepSeek / OpenAI 预设，或 Custom 填兼容 Base URL
            2. 
                
          2. API Key 来自对应服务商控制台；Model 填该服务商的模型名
            3. 
                
          3. 命令行：duaer live config --provider deepseek --api-key <key>
            4. 
              
          
            
          
          
          
        
          

        
          
          Cloudflare 部署
          
          
            
          保存后才会显示 Cloudflare 托管选项。密钥只存本机。
          
            
            
            
          
              
              
            
          
            
          
            
          
              怎么拿？
              
            
                
          1. 打开 Cloudflare Dashboard → 右侧 Account ID 复制
            2. 
                
          2. My Profile → API Tokens → Create Token；权限含 Workers / Pages 编辑
            3. 
                
          3. 粘贴 Token + Account ID → 保存；部署时会注入环境变量
            4. 
              
          
            
          
          
          
        
          

        
          
          阿里云部署
          
          
            
          保存后才会显示阿里云。密钥只存本机，不会回传页面。
          
            
            
            
          
              
              
            
          
            
          
            
          
              怎么拿？
              
            
                
          1. 打开 RAM AccessKey（建议子账号，最小权限）
            2. 
                
          2. 创建 AccessKey，复制 ID + Secret（Secret 只显示一次）
            3. 
                
          3. 粘贴保存；部署时注入 ALIBABA_CLOUD_ACCESS_KEY_*
            4. 
              
          
            
          
          
          
        
          

        
          
          AWS 部署
          
          
            
          保存后才会显示 AWS。密钥只存本机。
          
            
            
            
            
          
              
              
            
          
            
          
            
          
              怎么拿？
              
            
                
          1. 打开 IAM → Users → 选用户 → Security credentials
            2. 
                
          2. Create access key，复制 Access key ID + Secret
            3. 
                
          3. 可选填 Region（如 us-east-1）；部署时注入 AWS_* 环境变量
            4. 
              
          
            
          
          
          
        
          

        
          
          派工与模型说明
          
          
            
          Duaer 台面聊天模型 ≠ 派工用的数字员工 CLI，两边都要配好。
          

            
          数字员工 CLI（派工）
          
            
          派工只启动 Cursor Agent 或 Claude Code。未安装时派工卡会给出可复制命令。
          
            
          Cursor Agent
          
            
          curl https://cursor.com/install -fsS | bash
          
            
          Claude Code
          
            
          npm install -g @anthropic-ai/claude-code
          
            
          或官方安装脚本：curl -fsSL https://claude.ai/install.sh | bash
          

            
          其它模型怎么接
          
            
            
              
          • Duaer 台面用其它模型：选 Custom，填该服务商的 Base URL / Key / Model 名
            • 
              
          • 写代码要用 DeepSeek 等模型：把 Claude Code 接到对应 API（改 ~/.claude/settings.json 的 ANTHROPIC_*），派工仍选 Claude Code
            • 
              
          • Cursor Agent 的模型在 Cursor 账号/设置里选；FDE 只负责启动 agent
            • 
            
          
            
          完整步骤见 GitHub · worker-models.zh-CN.md
