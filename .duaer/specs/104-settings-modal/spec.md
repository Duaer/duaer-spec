# Brief: Settings drawer for model config

## Goal

Header control labeled 设置 (Settings). Model setup opens in the same
style of slide-over drawer as 项目 / create project — not a full-page
panel swap.

## Acceptance

1. Button text is 设置 / Settings (not 模型 / Model)
2. Click opens right drawer + backdrop like the project panel
3. First-time (not ready) auto-opens drawer; desk after save
4. Project and settings drawers do not both stay open
